独立密钥构建入口

从解压后的源码根目录开始，完整步骤以 README-BUILD.md 为准。准备 Python 3.11+（含 cryptography）、Node、JDK 25、Android platform/build-tools 36、NDK 27.3.13750724、CMake 和 Ninja，并先下载、校验上面两个外部输入。

先核对源码和生产输入绑定：

python -B build/rebuild139.py --verify-inputs-only

完整未签名 APK 路线（把占位路径换成本机路径；输出目录须为空）：

python -B build/rebuild139.py --out BUILD_OUT --sdk SDK --java-home JDK --mode full-unsigned --game-apk PUBLIC119_APK --frontend-supplement-zip IMAGES_ZIP

已有独立密钥 runtime 构建结果时，可使用收尾入口：

python -B build/finish-source-apk.py --runtime-build RUNTIME_OUT --out FINISH_OUT --sdk SDK --java-home JDK --game-apk PUBLIC119_APK --frontend-supplement-zip IMAGES_ZIP

收尾路线重建两种 ABI，并用临时本地证书处理构建载体；不需要私有历史 APK 或生产私钥。最终 assembled/candidate-aligned.apk 为未签名产物，runtime 使用调用者的本地密钥，不应预期与生产签名 APK 逐字节一致。

构建命令、输出、退出码和摘要记录在构建目录的 verification.json。完整构建复核与 Android 设备验收分别记录；提供这些入口不表示已完成线上发布或设备验收。
